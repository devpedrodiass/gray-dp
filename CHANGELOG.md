## 0.1.0

- Noir palette: neutral grays only, roles separated by luminance and font style.
- Three variants: Gray DP, Gray DP Black and Gray DP Light.
- Full workbench coverage with no default blue left.
- Tuned scopes for TS/TSX, JS, CSS, JSON, Markdown, Python, PHP, HTML, YAML and shell.
- Semantic tokens: declarations underlined, type parameters bold italic, deprecated struck through.
